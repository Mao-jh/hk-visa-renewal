# 香港身份续签·风险预审 · 集成支付 AI Skill

> 对话里直接问，出一份带编号依据的风险预审报告。按次付费（¥2.99/次），**无订阅**；
> 已内置**支付宝 AI 收（402）完整支付能力**，装完即用，无需另行安装任何官方支付组件。

## 这是什么

输入签证类型（高才通A/B/C/优才/IANG/专才）与个人情况（在港天数、工作与收入、雇佣形态、受养人、首签时间），返回续签风险报告：风险等级与置信度、逐条风险点（入境处执行口径条目编号+相似案例编号+补强建议）、六类签证续签要求对照表、续签必知（专属问卷/学历认证/两址两单）、断签后果说明。

## 安装（一句话）

```bash
git clone https://github.com/Mao-jh/hk-visa-renewal.git ~/.claude/skills/hk-visa-renewal
```

其他支持 skills 目录的 AI 客户端同理：把本仓库克隆/复制到对应 skills 目录即可。

## 怎么用

安装后在对话里直接问，例如：

- 「高才通续签要什么条件」
- 「我不在香港住能续签吗」
- 「优才续签会被拒吗」

流程：Agent 收集必要信息 → 调用后端 → 返回 402 待支付账单 → 内嵌支付流程拉起
**支付宝官方 `alipay-bot` CLI**（npm 包 `@alipay/agent-payment`，首次使用经完整性校验后安装）→
你用支付宝扫码付款 → 服务端验付 → 自动返回报告。支付判定以服务端校验为准，支付由用户本人确认。

## 定价

- **¥2.99 / 次**，按次收费，无订阅、无隐藏费用；与支付宝服务登记价完全一致。
- 收款走支付宝 AI 收（A2M/402 协议）：调用 → 402 账单 → 支付宝授权 → 验付 → 履约。

## 你会拿到什么

- `risk_level`：低 / 中 / 高，附置信度
- `hits[]`：逐条风险点，含**编号化依据**（口径条目 续签口径 / 案例库 + 相似案例编号），可信度可核验
- 六类签证续签要求对照表与续签必知（专属问卷/学历认证/两址两单）、断签后果
- 固定免责声明：本报告为**风险预审**（顾问位），不构成「必过/必拒」类保证

## 隐私

个人信息仅用于本次分析，服务端不留存。
